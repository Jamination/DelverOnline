HOSTING A DELVER ONLINE SERVER FOR FRIENDS
==========================================

Your network
------------
  This PC (local address):   192.168.7.208   (wired, enp4s0)
  Router / default gateway:  192.168.7.1     (Icotera i4882-01)
  Router admin page:         http://192.168.7.1
  Router login:              username "admin", password from the router sticker
  Public address:            149.13.193.50 is NOT yours alone: your ISP uses
                             carrier-grade NAT (shared address), so router port
                             forwarding can't work. Friends connect through a
                             playit.gg tunnel instead.
  Server port:               UDP 27960 (on this PC)

playit.gg tunnel (set up)
-------------------------
  Friends' address:          domination-spur.tun.ply.gg:55125   (UDP)
  Forwards to:               127.0.0.1:27960 on this PC
  Agent name on playit.gg:   "DelverOnline server" (your playit account)
  Agent program and key:     .tools/playit/ (playit, secret.key; not in git,
                             keep secret.key private)
  Start it:                  scripts/start-tunnel.sh
  Manage tunnels:            https://playit.gg (dashboard, log in with your account)

  The tunnel address stays the same unless you delete the tunnel. If you ever
  get a public IP from your ISP, the router rule (UDP 27960 -> 192.168.7.208)
  is still there and friends could use the public IP directly instead.

1. Build the executables (only after code changes)
--------------------------------------------------
  cd ~/Projects/DelverOnline
  ./gradlew release

  Results in build/release/:
    DelverOnline-linux-x64              the game with multiplayer
    DelverOnline-Server-linux-x64       the dedicated server
    DelverOnline-linux-x64.zip          both, plus the README
    DelverOnline-windows-x64.zip        Windows versions for friends on Windows

2. Start the server
-------------------
  build/release/DelverOnline-Server-linux-x64

  It loads all your installed Delver Workshop mods. To play without them, or with
  only some:
    build/release/DelverOnline-Server-linux-x64 --mods none
    build/release/DelverOnline-Server-linux-x64 --mods "Guns!,Moar Booty"

  It listens on UDP 27960. Then start the tunnel (step 2b).
  Leave both terminals open; type commands into the server's:
    help              list all commands
    players           who is connected (and whether a friend's connection arrived)
    mods              the mods your friends need (players with other mods are refused)
    status            server state
    say <text>        message everyone
    kick <name>       remove a player
    newrun            restart the dungeon
    stop              shut the server down

2b. Start the tunnel (second terminal)
--------------------------------------
  scripts/start-tunnel.sh

  It connects to playit.gg and forwards friends' traffic to the server here.
  Leave it running while you play; Ctrl+C stops it.

3. Give your friends the game
-----------------------------
  Each friend needs Delver (from Steam) and the zip for their system:
    Windows: DelverOnline-windows-x64.zip
    Linux:   DelverOnline-linux-x64.zip
  They unzip it and run DelverOnline-windows-x64.exe / DelverOnline-linux-x64.
  No Java install is needed. Everyone must use the same build as the server
  (a mismatch is refused with a "Version mismatch" message).

  Mods: friends need exactly the server's mods. This server loads every
  Delver Workshop mod installed on this PC (currently 7, see "mods" in the
  console). Send friends the list; they subscribe to the same items in Steam
  (Delver's Workshop page) and keep them enabled in Delver's Mods menu.
  Steam keeps them updated; a friend with an outdated copy is told so.

4. Joining
----------
  Friends:  main menu -> Multiplayer -> Server: domination-spur.tun.ply.gg:55125
                                     -> name -> Join
  You:      main menu -> Multiplayer -> Server: 127.0.0.1 -> name -> Join
            (joining through the tunnel address from this PC works too, but
            takes a detour through playit's servers)

If a friend cannot connect
--------------------------
  1. Is the server running? Type "status" in its console.
  2. Is the tunnel running? The scripts/start-tunnel.sh terminal must stay open,
     and the agent shows as online on the playit.gg dashboard.
  3. Did their connection attempt arrive? Type "players" in the console.
  4. Did they type the address exactly: domination-spur.tun.ply.gg:55125
     (the :55125 is required). Check the dashboard in case playit changed it.
  5. The server must use its default port 27960: the tunnel forwards to
     127.0.0.1:27960. If you start it with --port, edit the tunnel to match.

  If they see "Your mods don't match the server's": the message lists what to
  install or enable, what to disable, and which mods are a different version.
  Type "mods" in the server console for the exact list.

Notes
-----
  - Up to 8 players.
  - A player who drops out and rejoins with the same name during the same run
    gets their character back.
  - To run a second game window on this PC for testing:
      DELVERONLINE_NO_STEAM=1 DELVERONLINE_DATA=~/.local/share/DelverOnline-2 build/release/DelverOnline-linux-x64
